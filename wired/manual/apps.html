software included with Navi ~

go back

We want Navi to be a complete setup, ready to use out of the box the second it's installed.

To that effect, there is plenty of software pre-installed ready for you and ready to go. For development, gaming, writing, listening to music, watching videos, browsing the web, managing your files, jumping into a terminal, there is plenty of software here and ready for you the minute you fire up your NaviOS machine.

Here is a list of software you can find pre-installed on Navi, both written and/or forked by us, and hand-picked by us for inclusion into the distribution.

terminals

One of the most important pieces of software on GNU/Linux distros is their terminal emulators. We use terminals in order to interface directly with our machines, so having a great terminal available out of the box in order to issue commands and write scripts is important! We include a few terminals you can select from in Navi, and you can choose the one you like best, or install other terminals if you have a preference:

  • alacritty is a GPU-accelerated terminal emulator focused on simplicity and performance. It is the default terminal in wired.
  • foot is a fast terminal emulator for Wayland environments.
  • kitty is a feature-rich GPU-based terminal emulator.
  • sakura is a simple GTK terminal emulator.
  • stterm (st) is a super lightweight terminal emulator from the suckless project.
  • xterm is the classic X terminal emulator, always there when you need it.

file management

One of the core features any computer needs is a file manager so that you can organize all your stuff just how you like it. We include two file managers on Navi, so you can do things your own way.

  • nemo is a GTK file manager, and is set as the default. It has many helpful features, such as split-pane so you can view different directories at once, customizable toolbar, bookmarking, archive handling, and more. Perfect for those who want to handle their file management using a GUI.
  • nnn is a blazing-fast TUI file manager for those who want to handle their files from their terminal of choice.

web browsers

Browsing the web is something that everyone does these days, and in order to browse the web, you need a web browser, of course! We believe that web browsers should be free and open-source software so you can trust them, and as such, the web browsers we include inside of the distribution are all FOSS. Here are the ones we include:

  • Chromium is the FOSS codebase for Chrome and a multitude of other browsers, mostly maintained by Google.
  • Firefox ESR is the Extended Support Release of the independent, FOSS web browser from the Mozilla nonprofit.
  • elinks is a terminal-based web browser, allowing you to browse the web from the comfort of your favorite terminal emulator.
  • amfora is a terminal-based Gemini browser, allowing you to explore Geminispace.

development

As developers ourselves, we want Navi to be an inviting environment for other developers to fire up their machines and get to work in a great environment. To that end, we include development tools for everyone to use the tools they're comfortable with.

  • vim is the top-tier terminal-based text editor. Navi ships with our custom vim config, allowing you to open up your code in the terminal and get right to programming.

agents

Navi is an agent-native distro — AI agents are baked in from the first boot, not bolted on. Press Alt+A anywhere to pop up navi-Q with an agent ready to help, or Alt+Shift+A for a pop-up terminal. The agent lineup includes:

  • ollama runs large language models locally on your machine.
  • opencode is an agentic coding assistant for the terminal.
  • omp (oh my pi) is a standalone agent harness.
  • pi is an agent harness for the terminal.
  • crush is a glamorous agentic coding TUI.
  • herdr is an agent multiplexer for running multiple agents at once.

music players

Who doesn't love listening to their favorite music? We include a terminal-based music player and visualizer so you can get your jam on:

  • cmus is a terminal-based music player, allowing you to open up your music collection and listen through it quickly by using the keyboard, finding the music you want to play, and get it jamming.
  • cava is a terminal-based audio visualizer to go with it.

video players

Getting settled in with your favorite movies or TV shows from your local collection? We've got a video player built right in and ready to use for your viewing pleasure:

  • mpv is a lightweight video player that does right what it says on the tin - plays videos. An extremely simple UI, it shows you the content and media controls, and that's pretty much it.

nightshade software

The nightshade suite of software is our own set of tools available for you. Here are some of the pieces of nightshade software packed into the box with Navi:

  • naviApps is our nightshadeNeon app store — a curated catalog of webapps, ready to launch from your desktop.
  • navi radio is our music webapp for streaming tunes.
  • neighborli is our Fediverse instance based on Mastodon, and our webapp is included so you can join the Fediverse if you'd like to see what free and open-source social media is all about.
  • glyyph is our Nostr client. You can use it to explore Nostr, the distributed social protocol currently powering a swath of web applications.
  • FOSSfit is a health and fitness application. You can log your meals, track your health journey using the Journal, track your daily medications, set health goals, and more.

everything is here for you in the box

As you can see, there are all kinds of tools available for you and ready to go, packed in with Navi! You can use all of these tools right after installation, and of course, you can install any other software of your choosing! We also include support for Flatpak, so you have access to tons of software for Linux, and being Debian-based, Navi is also ready to install anything of your choosing using the apt package manager.
